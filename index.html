    이 조건으로 조각 쓰기

    여기까지 오는 길

    지금(2026년)부터 고른 해까지, 같은 조건에서 차례로 일어나는 일들입니다. 이미 지나간 일은 흐리게 표시됩니다.

      미래 조각 쓰기

      어떤 조건에서 어떤 일이 일어날지 한 장면으로 써 주세요. 쓴 조각은 GitHub에서 함께 검토한 뒤 이 웹사이트에 합쳐지고, 같은 조건을 고르는 모든 사람의 풍경에 나타납니다.

      분위기
      언제 일어나나요?

      체크한 조건이 모두 맞을 때 이 조각이 나타납니다. 범위를 좁힐수록 구체적인 미래가 됩니다.

      그림에 주는 변화 (선택)

      이 조각이 펼쳐질 때 풍경을 얼마나 바꿀지 정합니다. 0이면 바꾸지 않습니다.

      GitHub에 조각 보내기 아이디어로만 남기기

      ‘GitHub에 조각 보내기’를 누르면 파일이 채워진 GitHub 화면이 열립니다. 아래쪽 Propose changes → Create pull request를 누르면 끝입니다. GitHub 계정이 필요합니다.
